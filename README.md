# Movie Recommendation System

This project implements a content-based movie recommendation system using a Kaggle dataset and machine learning techniques.

## Project Overview
- Dataset Source: Kaggle
- Techniques Used: TF-IDF, Cosine Similarity
- Platform: Google Colab
- Duration: 12 January 2026 – 4 February 2026
